# /show-status — 查看任务状态

**作用**: 显示当前 PaperFit 任务的运行状态、缺陷消除进度和下一步行动

## 工具调用约定

若需读写状态文件以外的包内工具，在论文根目录使用 **`paperfit run scripts/state_manager.py …`**，勿将 `scripts/` 当作用户仓库内路径。

## 用法

```
/show-status
```

## 执行流程

1. 读取 `data/state.json` 获取当前状态
2. 格式化输出项目主文件、任务类型、当前轮次
3. 显示编译结果与页图渲染状态
4. 显示缺陷摘要（已修复/剩余）
5. 显示最近一次门禁决策及下一步行动
6. 显示诊断报告路径

## 输出内容

- 项目主文件
- 任务类型与约束
- 当前轮次 / 最大轮次
- 编译结果与页图渲染状态
- 缺陷摘要（已修复/剩余）
- 最近一次门禁决策及下一步行动
- 诊断报告路径

## 调度

- 直接读取 `data/state.json` 和诊断报告，不调用 Agent
